# Certificate Viewer

Локальный просмотрщик X.509-сертификатов, работающий полностью в браузере. Файлы не загружаются на сервер и не покидают устройство пользователя.

## Возможности

- PEM, DER, CER и CRT;
- несколько сертификатов в одном PEM-файле;
- Subject, Issuer, сроки действия, серийный номер;
- алгоритмы подписи и открытого ключа;
- расширения X.509 и неизвестные OID;
- SHA-256 и SHA-1 fingerprints;
- предупреждения о сроке действия, SHA-1 и самоподписанных сертификатах;
- копирование и экспорт JSON/PEM;
- Drag & Drop и `Ctrl+O`;
- статическая сборка для GitHub Pages.

## Запуск

```bash
npm install
npm run dev
```

Проверка проекта:

```bash
npm run check
```

## Ограничения

Приложение не использует системное хранилище доверенных корневых сертификатов и не выполняет сетевые проверки OCSP/CRL. Статус срока действия и структурный разбор не означают, что сертификату автоматически можно доверять.
